# Independent width and horizon review

The new sum-width certificates receive a qualified pass. The earlier range/horizon screen has a concrete histogram snapshot defect, which must be excluded or corrected in new evidence before those histograms are used.

`independent_audit.py` recomputed all 72 rows using scalar integer leakage and reset extrema at interval endpoints and the reset discontinuity. All 216 contract rows, high-base ranges, minimal signed widths, SIMD decisions, and explicit FF formulas matched. It verified the pinned source hashes, checked 8,580 reset intervals against enumeration, and checked 1,856,078 directed residue reconstructions. No counterexample to the interval/range certificates was found. This is a software proof audit, not a mapped hardware result.

The leakage is `ceil(beta*U/256)`, followed by one positive-threshold subtractive reset. The reset hull correctly accounts for the discontinuity at threshold. The original screen's simpler lower bound `lo=slo` is valid here because weight-derived current minima and propagated lower states are nonpositive, while thresholds are positive. This shortcut must not be generalized to strictly positive current intervals or other reset equations. Intersecting the finite recurrence with separately checked invariant intervals is sound for beta<256. Beta256 only has the declared finite-horizon certificate. The bounds cover arbitrary binary histories with the saved weights, rather than only observed test maxima; they do not prove all endpoint combinations are actually reachable in the network.

The stored high base is `floor(U/32)+floor(I/32)` and the exact reconstruction is `32*(base+carry)+low`. Narrow tail bases fit signed4, and shared-high tail deltas `floor(I/32)-floor(I0/32)` fit signed4. A new specialized RTL must sign-extend narrow stored metadata and add the carry at the reconstructed full high width. The endpoint assertions in the existing certificate program are not themselves an exhaustive implementation check; the audited algebra and directed checks support the mathematical construction, and a new bounded-domain RTL check is still required.

The native SIMD selection is fair in the new certificates: both operands and the sum must fit signed12 for FOUR12, or signed24 for TWO24. Using the membrane word width alone would give a misleading precision cliff in ten rows. For example, seed0/beta240/T32 has certified U=[-1289,447]; with any I8 the sum is [-1417,574], so FOUR12 is legal. A generic full signed12 membrane input instead gives sum [-2176,2174] and requires TWO24. At beta248/T32, seed2 still permits FOUR12 under its certified interval, even though seeds0/1 require TWO24. Any common multi-seed interface and any per-model specialization must be stated separately and applied equally to adaptive and fixed controls.

The FF expressions correctly count one valid bit, four count bits, high metadata or fabric sum registers for this one-edge architecture: fixed8 `5+8*b`, adaptive absolute `5+5*b+12`, union `5+5*b+15`, native hybrid `5+(8-lanes)*s`, and full LUT8 `5+8*s`. These are explicit fabric storage predictions, excluding DSP internal PREG and timing fixtures. They predict neither LUT/slice area nor timing/energy, and the union's extra reconstruction/multiplexing cost is unmeasured. A fully U8-certified case needs a strong static narrow fixed control; runtime checks confer no range advantage there. Strong comparisons should retain fixed packed DSP, legal native SIMD hybrid, full LUT, and the same adaptive policy in LUT arithmetic, with the same legal contract and interface.

Only beta224/T32 reproduces the original shift3 model equation and horizon in this screen. Other coefficients or horizons are openly declared numerical variants, with unchanged saved weights and thresholds. Beta128 with shift3 thresholds is not the original shift1 model. Three seeds of one ANN-to-SNN converted architecture do not establish independent trained-SNN architecture or AdEx generalization. A sum-width certificate cannot establish an accuracy improvement: exact hardware should preserve the particular declared reference outputs.

The screen's `finish(stat)` shallow-copies the statistics dictionary but retains its mutable nested `take_histogram`. Consequently T32 and T128 histograms are overwritten by the final T256 counts. `screen_snapshot_checks.json` identifies 144 invalid policy histograms and 72 valid T256 histograms. A concrete example is seed0/beta248/T32 absolute_U8: 27,897 scalar requests and 211,968 updates are paired with a histogram totaling 229,624 requests and 1,695,744 updates. Request counts, service counts, group/update counts, shared-wide scalar counts, digests, accuracy values, and interval certificates are scalar snapshots and are not changed by this aliasing. Fixed8 histograms are unpopulated zero placeholders and should not be presented as measured distributions.

The pinned original screen and certificates were not changed. A separately pinned repair is being prepared in `histogram_repair/` to recover all horizon histograms and verify that every other result field remains identical. Any next hardware trial should be chosen using the fair sum/high-base contract and all retained adverse results, rather than an inflated U+1 width or a changed coefficient chosen solely to favor DSP.
