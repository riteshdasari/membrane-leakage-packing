# Full-lane prefix policy screen

The software screen passed for k=1..8 on unchanged original IF, shift1 LIF and shift3 LIF ordered reference ledgers. It preserves every useful scalar operation, coefficient, neuron order, group boundary and threshold/reset result. Each configuration has9,216 groups and635,904 useful scalar updates from the first48 held-out images per saved seed. All ordinary sums, states and spikes were checked against the saved exact ledger, and every selected request was checked as a real48-bit packed addition with eight six-bit radix32 fields. Full lanes use signed13 U/signed8 I and a signed9 high field; admitted tails require actual signed8 U and signed4 high fields. No clipping or rescaling occurs.

For original IF, request counts at k1..8 are109,034;98,485;92,379;89,440;85,970;85,285;84,094;82,944. Analytic one-edge service clocks, including one drain clock per whole group, are118,250;107,701;101,595;98,656;95,186;94,501;93,310;92,160. The fixed-eight reference therefore remains the service lower bound. The k5 request histogram/count/service exactly matches the completed one-edge native DSP and direct adaptive-LUT IF cores. Existing four-edge LIF native counts also match k5, k6 and k8 policy counts, without relabeling their measured latency as one edge.

The one-bank DSP fabric-metadata count is37+5k bits: eight4-bit narrow high fields, five extra high bits per full lane, four count bits and one valid bit. The equivalent direct adaptive-LUT result/count/valid bank is77+5k bits: eight9-bit narrow results, five extra output bits per full lane, count and valid. A48-bit DSP PREG bank is also present in the DSP implementation. These are exact declared logical storage widths under the one-edge layout, not mapped FF/LUT estimates or a hardware-benefit claim. Range detectors, count masking, enables, DSP resources, routing, leakage/reset, operand delivery and memory costs require hardware evidence.

The worst numerical-domain service bound is sum over groups of ceil(N/k)+1 when every tail U is wide. Across these groups it equals645,120;327,168;225,792;170,496;138,240;119,808;105,984;92,160 clocks for k1..8. This bound is attainable with legal wide U values in every position. Input starvation and output backpressure can add waiting beyond this bound. Eight-value source availability is assumed; a two-value supply can remove the packing service opportunity. The bound is on this primitive's ordered admission and group-drain service, not full-neuron latency.

Original shift1 has the same82,944 requests and92,160 analytic clocks for every k. Its independent weight/leakage certificate guarantees U8 indefinitely, so a fixed all-U8 eight-lane core is the appropriate strong comparator. This workload supplies no need for runtime wide-tail admission.

Original shift3 has k1..8 requests85,831;84,561;83,642;83,251;82,948;82,948;82,944;82,944. Its k5 and k6 policies incur only four extra requests over fixed-eight on the whole sampled cohort, yet k4 incurs307extra requests. Individual seed/layer breakdowns and take histograms are preserved in the JSON. Admission is active where narrow tails reject, but a changing take does not itself imply fewer useful requests than full-range fixed-eight.

I do not recommend launching another k-variant RTL trial before the present k5 matched hardware and clean routed-replay evidence is resolved. The sweep offers a bounded tuning frontier, but no additional service benefit over fixed-eight. k4 would remove only five declared metadata bits relative to k5 while adding3,470 IF requests (3.65% one-edge service), plus an additional narrow-tail detector; shift3 adds303requests versus k5. k6 spends five more bits to save685IFrequests (0.72% service), while k7 spends ten more bits to save1,876IFrequests (1.97%). None creates a new mechanism or establishes a strong paper on its own. If a later measured k5 result identifies a specific storage/latency bottleneck, exactly one adjacent variant can be chosen against a declared target, with the same matched fixed and adaptive-LUT baselines. A new RTL sweep would currently broaden work without addressing the principal unproven advantage.

The restored references are three seeded64-128-10 ANN-to-integer-SNN conversions, with original coefficients and unchanged digits data. They are not independent architectures or directly trained SNNs. Original IF's input range is certified for32steps; the leaky settings have indefinite binary-input bounds. No new RTL, synthesis, route, energy or board job was run for this sweep. All input sources and completed native crosschecks are pinned; existing evidence remains unchanged.
