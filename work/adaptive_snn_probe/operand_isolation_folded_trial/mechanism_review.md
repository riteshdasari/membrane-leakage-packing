# Independent folded-selection isolation review

The sibling core changes only the module/default parameters and the current8 shared-corrector arithmetic operand construction. The original priority selector, selected lane, work/pending masks, classifiers, DSP, output assembly, registers, reset and ready/advance controls remain identical. The timing fixture differs only by renaming the core/fixture, selecting ISOLATE=1 and retaining the sole V3 top; original preservation attributes remain unchanged. The core adds no KEEP or DONT_TOUCH.

The unchanged priority selector produces a one-hot selected_mask for any nonzero work_mask and zero for no work. The new operand construction ORs each four-bit membrane high value and current sign after masking by its selected bit. Consequently all inactive lane terms vanish, and the active term equals the original selected-lane mux. With selected_mask zero, both masked operands become zero; selected_any then also forces the adjustment to zero. This folds isolation into selection without a separate v2-dependent arithmetic gate.

The independent script checks all 64 work masks, each lane's 16 possible high nibbles and all 64 current-sign vectors: 393,216 separable masked-selection cases. It also checks all 524,288 U11/I8 scalar pairs, including 229,376 exceptional pairs, using integer quotient/remainder algebra. For every exceptional pair, carry differs from current sign; hI plus carry is exactly ±1. The selected hU plus that adjustment reconstructs the exact signed12 U+I output.

Both original corrected_high write sites retain `correction_step && selected_mask[l]`. Every actual write implies a nonzero selected_mask, so the folded operands equal the original operands at each source write site. An independent enumeration checks this implication over 131,072 binary combinations of masks and controller inputs, including the last busy correction, reset and backpressure. These combinations form a superset of reachable states; this is not a sequential reachability proof. Backpressured exceptions and stale invalid exceptional metadata intentionally can keep arithmetic active. There is no path from the new operands back into selection, classification or scheduling.

The original postselection candidate and its review remain preserved separately. Its root-reported route failed 6 ns setup timing at WNS -0.230 ns, with 152 LUT / 268 FF / 1 DSP. The identified worst path runs through classification and advance into metadata CE, with routing dominant; it does not establish that the corrected_high adder caused the failure. The folded candidate tests a different mapping within the same correction mechanism. No improved timing, area, switching or energy is assumed.

This review establishes exact source boundaries, scalar algebra, one-hot selection and a combinational write implication. It does not replace the root's full native trace comparison, reset/backpressure suites, route checks, slow-corner SDF replay or matched SAIF/power audit. Synthesis may rewrite the operands; inspect the routed arithmetic cone and measured corrector activity before claiming isolation. Upstream classification still toggles, and the fixed DSP layout and lane count remain unchanged.

Run `review_operand_isolation.py` once to produce `review_checks.json`; run it with `--check` to reproduce the saved data without writing. The script launches no HDL tools and never modifies architecture sources. This is an independent subagent mechanism review; hardware and energy results belong to separate root execution evidence.
