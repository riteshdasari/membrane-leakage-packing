# Restored saved-reference admission study

The new helper restores the original saved integer SNN conversion without retraining, downloading, changing weights, changing held-out images, or replacing the original leakage coefficients. All nine saved configurations reproduce their saved 360-image reference accuracies exactly, with zero integer state, spike, output-count, or class disagreements.

These are three seeded 64-128-10 ReLU ANN models converted to an integer rate-coded SNN using quantized int4 weights and calibrated thresholds. They are not directly trained SNNs or three independent architectures. Each original reference uses 32 timesteps, subtractive reset, RNG seed 123, and the complete 360-image batch when drawing events. Using only the first 48 images when drawing events would produce a different random event sequence.

The two prepared bundles retain the original ordered first-48-image subset from that complete-batch reference. Each has 9,216 whole neuron groups and 635,904 scalar post-leak U plus current pairs. Every stream operand was independently read back against its ledger and checked for the declared signed11 U / signed8 I input domain. No invalid value is clipped or encoded. The stream header, group layout, and ledger fields support a new thin RTL-validation wrapper; the existing frozen verifier hardcodes the previous beta231 ledger path and must not be reused unchanged for a new accuracy claim.

For original shift1 leakage, full-set post-leak ranges are [-61,25], [-66,18], and [-53,23] for seeds 0, 1, and 2. Their saved accuracies are 96.11%, 95.56%, and 97.50%. Every sampled F5, F6, and fixed8 schedule uses 27,648 requests and 39,936 service clocks per seed; fixed6 uses 36,864 requests and 49,152 clocks.

Shift1 also admits a stronger static precision certificate: if a neuron's binary-spike current lies in [L,H], where L <= 0 <= H, then a state initialized at zero remains in [2L,2H] under ceil(state/2) + current and positive-threshold subtractive reset. Its post-leak U lies in [L,H]. Each neuron's signed8 current bound is certified from all negative and all positive weights, so a statically narrow eight-lane implementation is legal indefinitely for these weights and shift1 dynamics. Adaptive hardware should be compared against that candidate if shift1 is used to claim an advantage; no such implementation is measured here.

For original shift3 leakage, full-set post-leak ranges are [-301,98], [-426,106], and [-246,84]. Their saved accuracies are 96.11%, 94.72%, and 96.11%. All observed inputs fit U11/I8. F5 and F6 each use 27,648 requests / 39,936 service clocks for seeds 0 and 1, and 27,652 requests / 39,940 clocks for seed2. Fixed8 uses 27,648 / 39,936 for every seed, and fixed6 uses 36,864 / 49,152. The changing take histograms demonstrate actual membrane admission, but they do not establish a service-latency advantage over full-range fixed8. The aggregate F5/F6 cost is four extra requests/clocks over fixed8 across the same 635,904 useful updates.

The original IF configurations have full-set post-leak ranges [-1868,645], [-1863,437], and [-1119,341]. They violate U11 in 994, 2,232, and 10 scalar updates respectively. Their saved accuracies are reproduced in software, but no IF hardware stream is emitted and current RTL support is not claimed. Their scheduling numbers in the summary are explicitly hypothetical and unsupported by the current domain.

Software verification compares plain probe.reference arithmetic with independent residue reconstruction over every full-set integer update and a physical 48-bit packed addition over every supported sampled request. The unchanged primitive's global U11/I8 algebra certificate remains separate. No new native RTL replay, routed timing replay, board measurement, or power measurement was run in this study. Service clocks are request counts plus four drain clocks per whole group, with no output stalls. Only the first48 scheduling profile is exported; accuracy and numerical range use all360 images.

All source and artifact hashes are recorded in restored_reference_summary.json and manifest.json. Existing sources and previous evidence are unchanged. Original reset and leakage coefficients are restored; thresholds, weights, and data are the saved values. The current U+I primitive itself has no beta231 dependency. This removes the artificial-coefficient limitation for the supported reference configurations, while leaving the small architecture/workload sample and adaptive benefit claims limited by the measured evidence.
