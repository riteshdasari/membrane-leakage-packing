# Restored-reference native validation

This new trial compiles the frozen original six cores and all six frozen F5 sibling cores together. Engine IDs0..5 map to original E0..5; IDs6..11 map to F5 E0..5. Original and sibling engines0..4 must produce identical complete retirement files including clock stamps under the same stimulus and stalls. ID12 is a new statically narrow eight-lane signed8-U/signed8-I comparator enabled only for original shift1, where its domain is certified indefinitely from weight bounds. Its output and control pipeline use the common interface and four advancing edges.

Inputs are the frozen trained_reference_admission_study bundles for original shift1 or shift3 leakage and original subtractive reset. Each bundle has9,216 ordered groups and635,904 useful scalar updates from the first48 images per seed, while event generation and reference accuracy use the unchanged full360-image batch. No operand is clipped, rescaled or changed. IF is unsupported and excluded because signed11 U is violated. All incoming I is signed8 sign-extended to11bits. All consumed original/F5 U is signed11; static ID12 requires signed8 consumed U. Output12bits are exact sums and unused lanes are zero.

The native TB retains an independent ordinary-integer addition scoreboard, four-advance queue, group drains, source hold under backpressure, stable blocked output, and reset cancellation. The canceled in-flight prelude uses U127/I127 for all engines so the static comparator receives legal data. Poisoned unconsumed tails retain arbitrary wide values. Each leakage stream is tested with and without input/output stalls. CAPTURE_TRACE is disabled for these native-only runs unless a later new wrapper requests it; complete numeric retirements and TB completion metadata are preserved.

The new Python verifier independently checks every ordered retirement and then runs a feedback SNN check using actual retired sums: original fullbatch RNG input events, unchanged saved weights, actual previous hardware states, original leakage, propagated actual hardware spikes, thresholds and subtractive reset. It compares all sampled states/spikes/output counts/classes against the restored original ledger. Full360 accuracy restoration remains the separate frozen software study; sampled hardware validation is not a360-image board measurement.

Only low-memory native compile/elaborate/simulate/checker jobs are permitted here. They use a1.2GiB free-RAM launch gate and execute serially; root separately owns every synthesis, route, export, timing replay and power job. No such job is part of this runner. All inputs, frozen cores and new harness/helper sources are pinned before execution. Existing evidence is never overwritten.
