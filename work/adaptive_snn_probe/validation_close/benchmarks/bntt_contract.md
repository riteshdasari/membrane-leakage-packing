# Predeclared bounded independent vanilla-LIF validation

Model: the authors' TinyImageNet/VGG11 checkpoint linked by the Scientific Reports2021 visual-explanations implementation, source commit `178789c74fef72b9c25bd31d65ac598c987e1de9`. Do not substitute weights, retrain, alter T=30 or choose another leak. The original source default hidden-neuron leakage is0.99, threshold1, strict firing on old U>1, and reset subtracts the old spike in the next charge: `U_next=0.99*U_old+BN_t(W*input)-spike_old`. Output layer accumulates FP32 voltages and divides by30. Hidden nodes use their original per-timestep batch-normalization parameters.

The FP32 original will use its original AST with only parameterless `.cuda()` calls removed, retaining order of arithmetic, random input draws and class construction. CPU placement is not accuracy-preservation evidence vs the authors' CUDA result. The original model, plain integer model and actual packed integer model run separately with exactly matching input Poisson draws; for each image, reseed the same CPU generator with2021+canonical validation index before each execution. There is no timing early exit. The CPU original inference will not be compared against GPU checkpoint metadata as though it were independently reproduced published accuracy.

Inputs are the official64x64 TinyImageNet validation JPEGs. Apply the original `ToTensor` then ImageNet mean(.485,.456,.406), std(.229,.224,.225), without the visualization loader's128x128 resize. Map class IDs in sorted ImageFolder order. Use a deterministic64-image subset sampled without replacement from all10,000 validation images with NumPy generator seed20211001 and save exact selected IDs. No samples are chosen based on labels, range, packing or accuracy. Decode each JPEG directly from the pinned Stanford archive. Training and unlabeled test images are never used.

Declared integer-neuron conversion: membrane/current unit1/256; coefficient `RNE(0.99*256)=253`; effective BN/FP32 synaptic currents `I=RNE(current*256)`; leakage `L=ceil(253*U/256)`; old spike `S=(U>256)`; stored state `U_next=L+I-256*S`. Synapses, batch norm, pooling and readout remain FP32. This quantizes0.99 to253/256 and therefore is not lossless vs the FP32 neuron. Conversion accuracy is measured separately from packing preservation. There is no coefficient retuning, changed unit or saturation to make ranges favorable.

Packing uses the existing exact E5 signed9 reconstruction for adjacent actual nonzero membranes with the same fixed coefficient253; singleton products otherwise. Common zero bypass and original order remain fixed. Packed decoded values actually feed the state update. Every packed result is compared against independent scalar ceil. Plain integer vs packed integer feedback will compare every stored state and spike, then all output logits exactly. Operand and post-reset stored-state bounds are checked exhaustively; any old or new U outside signed16 is marked unsupported by the fixed16 hardware contract, while software retains exact values in its signed24 diagnostic domain. No clipping or representation change is permitted.

Run a one-image semantic/throughput probe after root coordinates RAM. If it passes, run the predeclared64 images, max4 CPU threads, initially batch1 to bound state-trace memory. Retain all attempted results. This is bounded cross-model validation, not full TinyImageNet accuracy, not a fully quantized SNN and not a board throughput or energy result. The full10,000 OTTT test has priority and must finish before launching this inference.

A strong constant-specific exact control is mandatory: `ceil(253*U/256) = U - floor(3*U/256)` for every signed integer U. Form3U as `(U<<1)+U` at a sufficient intermediate width, shift arithmetically by8, then subtract. This uses no DSP and remains exact for negative U. The fact that253/256 is not a power of two does not imply an expensive multiplier is required. This uniform-coefficient trained model is applicability/negative-control evidence, not proof of a general-coefficient DSP benefit. Keep beta253 fixed rather than retuning it to defeat this control; dynamic heterogeneous coefficients require a separate general-core comparison.
