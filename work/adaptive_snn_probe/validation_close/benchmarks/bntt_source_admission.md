Source `model.py` defines nine spiking hidden layers and an IF voltage readout. Hidden membranes have the actual recurrence `U_next = 0.99 U_old + BN_t(W spikes) - spike_old`, with threshold1, and `spike_old = (U_old > 1)`. Equality does not fire. Spikes/reset are evaluated from the old membrane before the current charge. Readout accumulates the final linear output and divides by30. This differs from OTTT's equality-firing, immediate-reset equation, and requires a separate faithful adapter. The released script constructs `SNN_VGG11()` with defaults `num_timestep=30` and `leak_mem=0.99`; CLI timestep/leak parameters are not passed to that constructor. All floating operations and update ordering must therefore be taken from actual source, not inferred from CLI labels.

Input uses signed Poisson events from normalized images: `sign(x) * [2r <= abs(x)]`, where `r` is a uniform random tensor drawn every timestep. The official validation transform is `ToTensor` then ImageNet normalization; there is no resize in the inference input, so native64x64 TinyImageNet validation images are required. The visualization-only loader separately resizes to128x128 and must not replace inference preprocessing. Comparison must reuse identical per-image/timestep random draws or reproducibly reseed each execution. Original validation class mapping must come from the dataset's canonical class IDs/annotation file.

This is a plausible nontrivial vanilla-LIF model: 0.99 cannot be implemented exactly by a power-of-two shift. Q8 coefficient `round(0.99*256)=253` would define a new integer-neuron conversion, rather than preserving FP32 leakage itself. If tested, freeze unit/coefficient/rounding/reset contract before inspecting packing rates; compare original-FP32 accuracy against that declared conversion, and compare plain integer against exact packed feedback. Do not claim the coefficient quantization is lossless or choose a different coefficient to improve DSP use. No accuracy, state-width applicability, packing rate, throughput or energy claim currently exists for this model.

Root's arithmetic review identifies an exact cheap constant control for that declared coefficient: `ceil(253U/256)=U-floor(3U/256)`. Form3U with shift/add, use arithmetic shift by8 for the floor, then subtract at a sufficient width. Thus this model also has a zero-DSP exact control despite its non-power-of-two coefficient. It provides broader true-LIF applicability and an honest negative/generalization boundary, not independent evidence that a DSP is intrinsically needed. General-core advantage must be measured on the declared dynamic/heterogeneous coefficient operation with the same strong LUT alternatives.
